AI Visibility Website – Time Breakdown (30 hours)

1.  Project setup and architecture ........... 2 h
    Astro + Tailwind scaffold, folder structure, design tokens, linting, CLAUDE.md draft

2.  Infrastructure and deploy pipeline ....... 2 h
    Cloudflare DNS, SSL, GitHub → Cloudflare Pages, production and preview deploys

3.  Layout and shared components ............. 3 h
    Base layout, header, mobile nav, footer, buttons, sections, cards, CTA, FAQ

4.  Page builds (5–6 pages) .................. 7 h
    All pages built from the design, semantic HTML, proper heading structure

5.  Responsive and cross-browser QA .......... 2 h
    360 / 768 / 1024 / 1440 px; Chrome, Safari, Firefox, Edge; iOS and Android

6.  Contact form and spam protection ......... 2.5 h
    Validation, serverless handler, Turnstile + honeypot, email notification

7.  Technical SEO ............................ 2.5 h
    Meta tags, canonical URLs, Open Graph, sitemap, robots.txt, JSON-LD schema, 404 page

8.  GEO/AEO readiness ........................ 1 h
    Static HTML content, AI crawler access, llms.txt, FAQ / question-led structure

9.  Performance and security hardening ....... 2 h
    Image and font optimisation, Lighthouse 95+, security headers (CSP, HSTS, etc.)

10. Analytics and Search Console ............. 1 h
    GA4 with form events, cookie consent, Search Console verification, sitemap submission

11. Claude → GitHub → production workflow .... 3 h
    CLAUDE.md, page template, README, GitHub Actions checks, branch protection, handover video

12. Final QA and launch ...................... 2 h
    Client feedback fixes, final validation, go live, indexing request

----------------------------------------------------------
TOTAL ........................................ 30 h
